概念

这是 minimal-course 的唯一示例章节，用于演示章节片段如何被 assemble 进 index.html。真实教程在 courses/<slug>/chapters/ 下按同样格式扩展。

本样例 domainType E 因此本章省略 Mermaid 与 Demo 块，校验仍可通过；章末可配合 quiz.partial.html 做测验。

参考

  • assembly.md — 组装说明
  • chapter-template.md — 章节模板
bash 
cd programming-html-tutorial
node scripts/assemble-index.mjs --dir examples/minimal-course
node scripts/validate-tutorial.mjs --dir examples/minimal-course
  1. 在侧栏点击各章，确认仅本章有正文。
  2. 向下滚动完成章节测验（单选 / 填空 / 多选）。
  3. 点击「标记完成」，观察顶栏进度与侧栏 ✓。

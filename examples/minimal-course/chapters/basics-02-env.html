JDK、Maven 与 Flink 发行包

组件推荐版本说明
JDK 17（LTS） Flink 2.x 官方文档以 Java 17 为主；确认 java -version 与 IDE Project SDK 一致。
Maven 3.9+ 用于生成 Walkthrough 工程、打包 fat JAR；mvn -v 应显示 JDK 17。
Flink 依赖 与教程一致 2.2.0 flink-streaming-java 为核心；Walkthrough 另需 flink-walkthrough-common（含 TransactionSource）。
Flink 发行包（可选） 2.2.x binary 仅在你需要手动 bin/start-cluster.sh 或 flink run 提交到已启动集群时下载；IDE 直接 Run 可跳过。

本课程 course.json 标注 Stable 为 2.2.x；若你对接 1.20 LTS 集群，请将依赖与文档版本改为集群一致，勿混用小版本连接器。

本地 Standalone 集群启动与 Web UI

Standalone 模式适合学习：一个 JobManager + 若干 TaskManager，Web UI 默认 http://localhost:8081。

两种本地运行方式

  subgraph ide["方式 A：IDE 直接 Run"]
    MAIN[FraudDetectionJob.main]
    MINI[内置 MiniCluster]
    LOG[TaskManager 日志 / AlertSink]
    MAIN --> MINI --> LOG
  end
  subgraph docker["方式 B：Docker Standalone + 可选提交"]
    UI[Web UI :8081]
    JM[JobManager]
    TM[TaskManager]
    UI --- JM
    JM --> TM
  end

学习路径建议：先用方式 A 在 IDE 打断点理解数据流；需要对照 Slot、作业列表时再用方式 B 打开 Web UI（与第一章 Demo 相同镜像）。

  • 发行包启动（已下载 binary 时）：解压后执行 bin/start-cluster.sh（Windows 为 bin\start-cluster.bat），浏览器访问 8081。
  • Docker 启动：见本章 Demo，docker compose up -d 后访问 8081；停止用 docker compose down。
  • Web UI 看什么：Overview 中 TaskManager 数量与 Slot；提交作业后 Jobs 页可见 RUNNING 状态与 Task 拓扑。

DataStream 官方教程：欺诈检测骨架

Apache 提供 Maven Archetype，一键生成带 TransactionSource、AlertSink 的完整工程，业务逻辑在 FraudDetector（KeyedProcessFunction）中填写。

欺诈检测 Walkthrough 管道
flowchart LR
  TS[TransactionSource]
  KB[keyBy accountId]
  FD[FraudDetector]
  AS[AlertSink]
  TS --> KB --> FD --> AS

管道记忆：有界/无界 Source → 按账户分区 → 有状态 规则判断 → Sink 输出告警（本 Walkthrough 打印到控制台）。

示例代码：生成 Walkthrough 工程

bash 
# 生成官方 Walkthrough 工程（Flink 2.2.0）
mvn archetype:generate \
  -DarchetypeGroupId=org.apache.flink \
  -DarchetypeArtifactId=flink-walkthrough-datastream-java \
  -DarchetypeVersion=2.2.0 \
  -DgroupId=frauddetection \
  -DartifactId=frauddetection \
  -Dversion=0.1 \
  -Dpackage=spendreport \
  -DinteractiveMode=false

cd frauddetection
mvn clean package

# 可选：flink run -c spendreport.FraudDetectionJob target/frauddetection-0.1.jar

示例代码：FraudDetectionJob 骨架

java 
StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();

DataStream<Transaction> transactions = env
    .addSource(new TransactionSource())
    .name("transactions");

DataStream<Alert> alerts = transactions
    .keyBy(Transaction::getAccountId)
    .process(new FraudDetector())
    .name("fraud-detector");

alerts.addSink(new AlertSink()).name("send-alerts");

env.execute("Fraud Detection");

在 IDE 中运行与打包提交

场景做法注意
IDE 本地 Run 运行 FraudDetectionJob.main IntelliJ 若报 NoClassDefFoundError：Run Configuration → Modify options → 勾选 include dependencies with "Provided" scope。
打包可提交 JAR mvn clean package 使用 archetype 自带的 shade 配置，产物在 target/*.jar。
提交到 Standalone flink run -c spendreport.FraudDetectionJob target/frauddetection-0.1.jar 需已设置 FLINK_HOME 且集群已启动；-c 为全限定主类名。
本章小结：能用 Archetype 生成工程并在 IDE 跑通 FraudDetectionJob；知道 IDE 本地跑与 flink run 提交的区别；会在 Web UI 看到 TaskManager。过关后进入 basics-03-datastream，系统学习 map、keyBy 与执行图。

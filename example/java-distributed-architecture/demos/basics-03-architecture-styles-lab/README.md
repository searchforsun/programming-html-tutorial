# 架构形态与团队拓扑实验室

本章配套**纸面/笔记练习**，无需启动 Spring 工程。对应章节「动手练习」第 3 步。

## 目标

- 区分分层单体与模块化单体的模块依赖规则
- 用康威定律检查服务边界是否与团队对齐
- 在「立即拆微服务」与「模块化单体」之间做有依据的选择

## 练习 1：模块化单体依赖图

在纸上画出：

```text
shopflow-app (启动器)
  ├── shopflow-order
  ├── shopflow-inventory
  └── shopflow-payment
```

用箭头标出**允许**的依赖（例如 order → inventory 门面），并写一条**禁止**规则（例如 inventory 不得依赖 order 的 entity 包）。
